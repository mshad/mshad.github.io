02About Me

Hi! I'm Matthias — born on a mild winter day in Wrocław, Poland. My first computer could display an incredible number of 4 colors in CGA mode. I started programming in middle school, became fascinated with real-time graphics, and never really stopped being a computer-geek 🤓.

Besides being a specialist for 3D programming, I'm an allrounder for technical topics: game engines, web apps, microcontrollers, large-scale server clusters. I can move from quick prototype to maintainable production code as needed.

Writing code as part of an interdisciplinary team is what inspires me — in a good group, talents complement each other. I value an agile mindset and iterative ways of working, and as an IHK-certified trainer (Ausbilder, Fachinformatiker Anwendungsentwicklung) I enjoy passing knowledge on.

Away from the keyboard I go on bikepacking trips, hike, hunt for treasures at flea markets, or try out new recipes in the kitchen.

  • 17+ years in real-time graphics
  • DE / EN / PL languages spoken
